## What is OpenCBS Cloud?

OpenCBS Cloud is a flexible and scalable **Core Banking System** designed for rapid deployment. Unlike legacy banking systems that take months or years to implement, OpenCBS Cloud can be deployed within weeks.

Built from 2017 onwards as an open-source solution, it provides all essential front-office and back-office features needed by:

- **Microfinance Institutions**
- **Cooperative Financial Institutions**
- **Digital Lenders**
- **Medium-sized Banks**

## Key Capabilities

<AccordionGroup>
  <Accordion title="Client Management" icon="users">
    Manage individuals, companies, and groups with comprehensive profile tracking, custom fields, and relationship management.
  </Accordion>

  <Accordion title="Loan Operations" icon="hand-holding-dollar">
    Full loan lifecycle management including origination, flexible scheduling, repayments, and portfolio tracking with support for multiple loan products.
  </Accordion>

  <Accordion title="Savings & Deposits" icon="piggy-bank">
    Manage savings accounts, term deposits, bonds, and borrowings with automated interest calculations and maturity handling.
  </Accordion>

  <Accordion title="Accounting & Reporting" icon="chart-line">
    Comprehensive double-entry accounting system with real-time balance sheets, configurable reports, and audit trails.
  </Accordion>
</AccordionGroup>

## Technology Stack

OpenCBS Cloud is built with modern, proven technologies:

<Tabs>
  <Tab title="Backend">
    - **Java 8** with Spring Boot framework
    - **Maven** multi-module architecture
    - **PostgreSQL** database with Flyway migrations
    - **REST API** for all operations
    - **Spring Security** for authentication and authorization
  </Tab>
  <Tab title="Frontend">
    - **Angular 8** framework
    - **Angular Material** components
    - **NgRx** state management
    - **TypeScript** for type safety
    - **Responsive design** for all screen sizes
  </Tab>
  <Tab title="Infrastructure">
    - **Docker** containerization
    - **Nginx** web server
    - **JasperReports** for PDF generation
    - **WebSocket** for real-time updates
  </Tab>
</Tabs>

## Get Started

<Steps>
  <Step title="Install Prerequisites">
    Ensure you have Java 8+, Node.js 10+, PostgreSQL 9.6+, and Maven 3.6+ installed on your system.
  </Step>
  
  <Step title="Clone the Repository">
    Download the OpenCBS Cloud source code from the official GitHub repository.
  </Step>
  
  <Step title="Configure Database">
    Set up your PostgreSQL database and configure connection settings.
  </Step>
  
  <Step title="Build and Deploy">
    Use the provided build scripts to compile and deploy the application.
  </Step>
</Steps>
