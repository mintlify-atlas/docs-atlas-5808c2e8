## Savings Products

### Product Structure

Savings products define the terms and conditions for savings accounts:

```java
@Entity
@Table(name = "saving_products")
public class SavingProduct extends NamedBaseEntity {
    @Column(name = "code", nullable = false)
    private String code;
    
    @Column(name = "availability", nullable = false)
    private int availability;
    
    @ManyToOne
    @JoinColumn(name = "currency_id", nullable = false)
    private Currency currency;
    
    // Initial amount constraints
    @Column(name = "initial_amount_min", precision = 14, scale = 2, nullable = false)
    private BigDecimal initialAmountMin;
    
    @Column(name = "initial_amount_max", precision = 14, scale = 2, nullable = false)
    private BigDecimal initialAmountMax;
    
    // Interest rate configuration
    @Column(name = "interest_rate_min", precision = 8, scale = 4, nullable = false)
    private BigDecimal interestRateMin;
    
    @Column(name = "interest_rate_max", precision = 8, scale = 4, nullable = false)
    private BigDecimal interestRateMax;
    
    @Enumerated(EnumType.STRING)
    @Column(name = "interest_accrual_frequency", nullable = false)
    private Frequency interestAccrualFrequency;
    
    @Enumerated(EnumType.STRING)
    @Column(name = "posting_frequency", nullable = false)
    private Frequency postingFrequency;
    
    @Column(name = "capitalized")
    private boolean capitalized;
    
    @Column(name = "min_balance", nullable = false)
    private BigDecimal minBalance = BigDecimal.ZERO;
    
    @Enumerated(EnumType.STRING)
    @Column(name="status", nullable = false)
    private StatusType statusType = StatusType.ACTIVE;
}
```

<Accordion title="Product Configuration Fields">
  - **Code**: Unique product identifier (e.g., "SAV001", "TIME_DEPOSIT_12M")
  - **Availability**: Which profile types can open accounts (bitmap)
  - **Currency**: Base currency for the product
  - **Initial Amount**: Min/max opening balance requirements
  - **Interest Rate**: Allowable rate range (annual percentage)
  - **Interest Accrual Frequency**: How often interest is calculated (daily, monthly, etc.)
  - **Posting Frequency**: When interest is added to account (monthly, quarterly, etc.)
  - **Capitalized**: Whether interest compounds (added to principal)
  - **Min Balance**: Minimum balance to avoid fees or earn interest
  - **Status**: Product availability (ACTIVE, INACTIVE)
</Accordion>

    @Enumerated(EnumType.STRING)

## Interest Calculation

### Accrual Process

Interest accrues based on the configured frequency:

```java
@Enumerated(EnumType.STRING)
@Column(name = "interest_accrual_frequency", nullable = false)
private Frequency interestAccrualFrequency;
```

**Accrual Calculation:**
1. Daily balance tracked
2. Interest calculated: `Balance × (Annual Rate / Days in Year) × Days`
3. Accrued interest accumulated
4. Posted to account on posting frequency

### Interest Posting

```java
@Enumerated(EnumType.STRING)
@Column(name = "interest_posting_frequency", nullable = false)
private Frequency interestPostingFrequency;
```

On posting date:
1. Calculate total accrued interest since last posting
2. Create accounting entry (Debit: Interest Expense, Credit: Savings Account)
3. If capitalized, add interest to principal balance
4. Reset accrual tracking

### Capitalization

```java
@Column(name = "capitalized", nullable = false)
private boolean capitalized;
```

- **Capitalized = true**: Interest added to principal, earns interest in next period
- **Capitalized = false**: Interest credited but doesn't earn interest

<Accordion title="Interest Calculation Example">
  **Scenario:**
  - Balance: $10,000
  - Annual Interest Rate: 6%
  - Accrual Frequency: Daily
  - Posting Frequency: Monthly
  - Capitalized: Yes
  
  **Month 1:**
  - Daily Interest = $10,000 × (6% / 365) = $1.64
  - 30 Days = $1.64 × 30 = $49.32
  - Posted at month end, new balance = $10,049.32
  
  **Month 2:**
  - Daily Interest = $10,049.32 × (6% / 365) = $1.65
  - Interest compounds on previous interest
</Accordion>
