## Overview

The Configuration API provides endpoints for managing system-wide settings, global parameters, and application configuration in OpenCBS. These settings control core system behavior and functionality.

## Global Settings

Global settings are system-wide configuration parameters that affect the entire OpenCBS instance.

### Get All Global Settings

Retrieve all global settings configured in the system.

```http
GET /api/global-settings
```

### Response

Returns an array of all global settings.

<ResponseField name="[].name" type="string">
  Setting name/identifier (used as key)
</ResponseField>

<ResponseField name="[].value" type="string">
  Setting value
</ResponseField>

<ResponseField name="[].type" type="string">
  Data type of the setting (e.g., "STRING", "NUMBER", "BOOLEAN")
</ResponseField>

<ResponseField name="[].description" type="string">
  Human-readable description of the setting
</ResponseField>

<CodeGroup>
```bash cURL
curl -X GET https://your-instance.opencbs.cloud/api/global-settings \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```javascript JavaScript
const response = await fetch('https://your-instance.opencbs.cloud/api/global-settings', {
  headers: {
    'Authorization': 'Bearer YOUR_TOKEN'
  }
});
const settings = await response.json();
```
</CodeGroup>

### Get Global Setting by Name

Retrieve a specific global setting by its name.

```http
GET /api/global-settings/{name}
```

#### Path Parameters

<ParamField path="name" type="string" required>
  The unique name/identifier of the global setting
</ParamField>

#### Response

<ResponseField name="name" type="string">
  Setting name
</ResponseField>

<ResponseField name="value" type="string">
  Setting value
</ResponseField>

<ResponseField name="type" type="string">
  Data type of the setting
</ResponseField>

<CodeGroup>
```bash cURL
curl -X GET https://your-instance.opencbs.cloud/api/global-settings/SYSTEM_TIMEZONE \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```javascript JavaScript
const settingName = 'SYSTEM_TIMEZONE';
const response = await fetch(`https://your-instance.opencbs.cloud/api/global-settings/${settingName}`, {
  headers: {
    'Authorization': 'Bearer YOUR_TOKEN'
  }
});
const setting = await response.json();
```
</CodeGroup>

## System Settings

System settings are configurable custom fields that control various aspects of system behavior.

### Get All System Settings

Retrieve all system settings with their current values.

```http
GET /api/system-settings
```

### Response

Returns an array of system setting objects.

<ResponseField name="[].customField" type="object">
  Custom field definition containing:
  - `id` - Field identifier
  - `name` - Field name
  - `fieldType` - Type of field (TEXT, NUMBER, BOOLEAN, etc.)
  - `caption` - Display label
</ResponseField>

<ResponseField name="[].value" type="string">
  Current value of the setting
</ResponseField>

<CodeGroup>
```bash cURL
curl -X GET https://your-instance.opencbs.cloud/api/system-settings \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```javascript JavaScript
const response = await fetch('https://your-instance.opencbs.cloud/api/system-settings', {
  headers: {
    'Authorization': 'Bearer YOUR_TOKEN'
  }
});
const systemSettings = await response.json();
```
</CodeGroup>

### Update System Settings

Update one or more system settings.

```http
PUT /api/system-settings
```

#### Request Body

Array of system setting update objects.

<ParamField body="[].customField.id" type="number" required>
  ID of the custom field (system setting) to update
</ParamField>

<ParamField body="[].value" type="string" required>
  New value for the setting
</ParamField>

#### Response

Returns the updated system settings array.

<CodeGroup>
```bash cURL
curl -X PUT https://your-instance.opencbs.cloud/api/system-settings \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '[
    {
      "customField": {
        "id": 1
      },
      "value": "new_value"
    },
    {
      "customField": {
        "id": 2
      },
      "value": "another_value"
    }
  ]'
```

```javascript JavaScript
const updates = [
  {
    customField: { id: 1 },
    value: 'new_value'
  },
  {
    customField: { id: 2 },
    value: 'another_value'
  }
];

const response = await fetch('https://your-instance.opencbs.cloud/api/system-settings', {
  method: 'PUT',
  headers: {
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(updates)
});
const updatedSettings = await response.json();
```
</CodeGroup>

## Application Configuration

Application-level configuration endpoints.

### Get RabbitMQ Credentials

Retrieve RabbitMQ (AMQP) connection credentials for message queue integration.

```http
GET /api/configurations/rabbit-credential
```

#### Response

<ResponseField name="host" type="string">
  RabbitMQ server hostname
</ResponseField>

<ResponseField name="port" type="number">
  RabbitMQ server port
</ResponseField>

<ResponseField name="username" type="string">
  RabbitMQ username
</ResponseField>

<ResponseField name="password" type="string">
  RabbitMQ password
</ResponseField>

<ResponseField name="virtualHost" type="string">
  RabbitMQ virtual host
</ResponseField>

<CodeGroup>
```bash cURL
curl -X GET https://your-instance.opencbs.cloud/api/configurations/rabbit-credential \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```javascript JavaScript
const response = await fetch('https://your-instance.opencbs.cloud/api/configurations/rabbit-credential', {
  headers: {
    'Authorization': 'Bearer YOUR_TOKEN'
  }
});
const rabbitConfig = await response.json();
```
</CodeGroup>

## Common Global Settings

Here are some commonly used global settings you might encounter:

<ResponseField name="SYSTEM_TIMEZONE" type="string">
  System timezone (e.g., "America/New_York", "UTC")
</ResponseField>

<ResponseField name="DATE_FORMAT" type="string">
  Default date format for the system
</ResponseField>

<ResponseField name="DECIMAL_PLACES" type="number">
  Number of decimal places for currency calculations
</ResponseField>

<ResponseField name="BASE_CURRENCY" type="string">
  Default currency code (e.g., "USD", "EUR")
</ResponseField>

<ResponseField name="ORGANIZATION_NAME" type="string">
  Name of the financial organization
</ResponseField>

## Error Responses

<ResponseField name="404" type="error">
  Setting not found - The requested setting name does not exist
</ResponseField>

<ResponseField name="400" type="error">
  Validation error - Invalid value for the setting type
</ResponseField>

<ResponseField name="401" type="error">
  Unauthorized - Invalid or missing authentication token
</ResponseField>

<ResponseField name="403" type="error">
  Forbidden - Insufficient permissions to modify settings
</ResponseField>

## Best Practices

<Warning>
  Be extremely careful when modifying system settings and global settings. Incorrect values can cause system instability or unexpected behavior.
</Warning>

<Tip>
  Always test configuration changes in a development or staging environment before applying them to production.
</Tip>

<Note>
  Some system settings may require a system restart or cache clear to take effect. Consult your system administrator before making changes.
</Note>

## Security Considerations

- Access to configuration endpoints should be restricted to administrators only
- RabbitMQ credentials are sensitive and should be handled securely
- Audit all configuration changes for security and compliance
- Use HTTPS for all API calls to prevent credential exposure
