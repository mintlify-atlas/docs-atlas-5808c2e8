## Overview

The Tills API provides endpoints for managing tills (cash drawers), including opening/closing operations, deposits, withdrawals, and transfers between tills and vaults.

## Get All Tills

<CodeGroup>
```http GET /api/tills
GET /api/tills?page={page}&size={size}&search={search}
```
</CodeGroup>

Retrieve all tills with pagination and optional search.

### Query Parameters

<ParamField query="page" type="integer">
  Page number for pagination (0-based)
</ParamField>

<ParamField query="size" type="integer">
  Number of items per page
</ParamField>

<ParamField query="search" type="string">
  Search term to filter tills
</ParamField>

### Response

<ResponseField name="content" type="array">
  Array of till objects
  <ResponseField name="id" type="long">
    Till ID
  </ResponseField>
  <ResponseField name="name" type="string">
    Till name
  </ResponseField>
  <ResponseField name="branchId" type="long">
    Branch ID
  </ResponseField>
  <ResponseField name="vaultId" type="long">
    Associated vault ID
  </ResponseField>
  <ResponseField name="isOpened" type="boolean">
    Whether the till is currently open
  </ResponseField>
  <ResponseField name="tellerId" type="long">
    ID of the teller currently using the till
  </ResponseField>
</ResponseField>

## Create Till

<CodeGroup>
```http POST /api/tills
POST /api/tills
Content-Type: application/json
```

```json Request Body
{
  "name": "Teller 1 Cash Drawer",
  "branchId": 1,
  "vaultId": 1,
  "accounts": [
    {
      "currencyId": 1
    }
  ]
}
```
</CodeGroup>

Create a new till.

### Request Body

<ParamField body="name" type="string" required>
  Till name
</ParamField>

<ParamField body="branchId" type="long" required>
  Branch ID where the till is located
</ParamField>

<ParamField body="vaultId" type="long" required>
  ID of the vault associated with this till
</ParamField>

<ParamField body="accounts" type="array" required>
  Array of account configurations
  <ParamField body="currencyId" type="long" required>
    Currency ID for each account
  </ParamField>
</ParamField>

### Response

Returns the created till object with the same structure as Get Till by ID.

## Open Till

<CodeGroup>
```http POST /api/tills/{id}/open
POST /api/tills/{id}/open?tellerId={tellerId}
```
</CodeGroup>

Open a till for a specific teller to begin operations.

### Path Parameters

<ParamField path="id" type="long" required>
  Till ID
</ParamField>

### Query Parameters

<ParamField query="tellerId" type="long" required>
  ID of the teller opening the till
</ParamField>

### Permissions

Requires `OPEN_TILL` permission in the `TELLER_MANAGEMENT` module.
