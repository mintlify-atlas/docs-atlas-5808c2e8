---
title: "Loans API"
description: "Manage loan accounts, schedules, events, and operations"
---

The Loans API provides endpoints to manage active loan accounts, including retrieving loan details, viewing schedules, processing operations like write-offs, and managing loan events.

## Get All Loans

<Expandable title="GET /api/loans">
  <ParamField query="search" type="string">
    Search term to filter loans by borrower name, loan code, or other criteria
  </ParamField>

  <ParamField query="page" type="integer">
    Page number for pagination (0-indexed)
  </ParamField>

  <ParamField query="size" type="integer">
    Number of results per page
  </ParamField>

  **Response**

  <ResponseField name="content" type="array">
    Array of simplified loan objects
    
    <Expandable title="Loan Object">
      <ResponseField name="id" type="long">
        Unique loan identifier
      </ResponseField>

      <ResponseField name="code" type="string">
        Loan account code
      </ResponseField>

      <ResponseField name="profile" type="object">
        Borrower profile information
      </ResponseField>

      <ResponseField name="amount" type="decimal">
        Loan principal amount
      </ResponseField>

      <ResponseField name="interestRate" type="decimal">
        Annual interest rate percentage
      </ResponseField>

      <ResponseField name="status" type="string">
        Current loan status (ACTIVE, CLOSED, WRITTEN_OFF, etc.)
      </ResponseField>

      <ResponseField name="maturityDate" type="string">
        Loan maturity date in ISO format
      </ResponseField>

      <ResponseField name="loanOfficer" type="object">
        Assigned loan officer details
      </ResponseField>

      <ResponseField name="loanProductName" type="string">
        Name of the loan product
      </ResponseField>
    </Expandable>
  </ResponseField>

  <ResponseField name="totalElements" type="long">
    Total number of loans matching the query
  </ResponseField>

  <ResponseField name="totalPages" type="integer">
    Total number of pages
  </ResponseField>

  <CodeGroup>
  ```bash cURL
  curl -X GET "https://api.opencbs.com/api/loans?search=John&page=0&size=20" \
    -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
  ```

  ```javascript JavaScript
  const response = await fetch('https://api.opencbs.com/api/loans?search=John&page=0&size=20', {
    headers: {
      'Authorization': 'Bearer YOUR_ACCESS_TOKEN'
    }
  });
  const loans = await response.json();
  ```

  ```python Python
  import requests

  response = requests.get(
    'https://api.opencbs.com/api/loans',
    params={'search': 'John', 'page': 0, 'size': 20},
    headers={'Authorization': 'Bearer YOUR_ACCESS_TOKEN'}
  )
  loans = response.json()
  ```
  </CodeGroup>
</Expandable>

## Write Off Loan

<Expandable title="POST /api/loans/{loanId}/write-off">
  Write off a loan account (marks non-recoverable debt).

  <ParamField path="loanId" type="long" required>
    Loan identifier
  </ParamField>

  **Request Body**

  <ParamField body="date" type="datetime" required>
    Effective date and time of the write-off
  </ParamField>

  <ParamField body="comment" type="string">
    Reason or notes for the write-off
  </ParamField>

  <CodeGroup>
  ```bash cURL
  curl -X POST "https://api.opencbs.com/api/loans/12345/write-off" \
    -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "date": "2024-03-15T10:00:00",
      "comment": "Borrower bankruptcy"
    }'
  ```

  ```javascript JavaScript
  const response = await fetch('https://api.opencbs.com/api/loans/12345/write-off', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_ACCESS_TOKEN',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      date: '2024-03-15T10:00:00',
      comment: 'Borrower bankruptcy'
    })
  });
  ```

  ```python Python
  import requests

  response = requests.post(
    'https://api.opencbs.com/api/loans/12345/write-off',
    headers={'Authorization': 'Bearer YOUR_ACCESS_TOKEN'},
    json={
      'date': '2024-03-15T10:00:00',
      'comment': 'Borrower bankruptcy'
    }
  )
  ```
  </CodeGroup>
</Expandable>

## Specific Provision Operations

<Expandable title="Provisioning Endpoints">
  Manage loan loss provisions for specific loans.

  ### Get Provision Information
  
  **GET /api/loans/{loanId}/specific-provision/{provisionType}**

  <ParamField path="loanId" type="long" required>
    Loan identifier
  </ParamField>

  <ParamField path="provisionType" type="string" required>
    Type of provision (MANUAL or AUTOMATIC)
  </ParamField>

  **Response**: Provision information including current reserve amount and percentage.

  ### Recalculate Provision by Percent
  
  **GET /api/loans/{loanId}/recalculate-specific-provision/{value}/{provisionType}/by-percent**

  Calculate the reserve amount based on a percentage.

  <ParamField path="loanId" type="long" required>
    Loan identifier
  </ParamField>

  <ParamField path="value" type="decimal" required>
    Provision percentage (e.g., 5.5 for 5.5%)
  </ParamField>

  <ParamField path="provisionType" type="string" required>
    Type of provision
  </ParamField>

  **Response**: Calculated reserve amount

  ### Recalculate Provision by Amount
  
  **GET /api/loans/{loanId}/recalculate-specific-provision/{value}/{provisionType}/by-amount**

  Calculate the percentage based on a reserve amount.

  <ParamField path="loanId" type="long" required>
    Loan identifier
  </ParamField>

  <ParamField path="value" type="decimal" required>
    Reserve amount
  </ParamField>

  <ParamField path="provisionType" type="string" required>
    Type of provision
  </ParamField>

  **Response**: Calculated percentage

  ### Apply Specific Provision
  
  **POST /api/loans/apply-specific-provision**

  Apply a specific provision to a loan.

  **Request Body**

  <ParamField body="loanId" type="long" required>
    Loan identifier
  </ParamField>

  <ParamField body="provisionType" type="string" required>
    Type of provision
  </ParamField>

  <ParamField body="percent" type="decimal" required>
    Provision percentage
  </ParamField>

  <ParamField body="amount" type="decimal" required>
    Reserve amount
  </ParamField>

  <CodeGroup>
  ```bash cURL
  curl -X POST "https://api.opencbs.com/api/loans/apply-specific-provision" \
    -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "loanId": 12345,
      "provisionType": "MANUAL",
      "percent": 10.0,
      "amount": 5000.00
    }'
  ```
  </CodeGroup>
</Expandable>
