---
title: "Repayments API"
description: "Process loan repayments and view payment schedules"

The Repayments API handles all loan repayment operations, including calculating repayment splits, previewing payment impacts, and processing actual repayments through the maker-checker workflow.

## Calculate Repayment Split

<Expandable title="POST /api/loans/{loanId}/repayment/split">
  Calculate how a payment amount will be split across principal, interest, penalties, and fees.

  <ParamField path="loanId" type="long" required>
    Loan identifier
  </ParamField>

  **Request Body**

  <ParamField body="timestamp" type="datetime" required>
    Effective date and time of the payment
  </ParamField>

  <ParamField body="total" type="decimal" required>
    Total payment amount
  </ParamField>

  <ParamField body="repaymentType" type="string" required>
    Type of repayment (NORMAL_REPAYMENT, EARLY_TOTAL_REPAYMENT, EARLY_PARTIAL_REPAYMENT)
  </ParamField>

  <ParamField body="paymentMethod" type="long" required>
    Payment method identifier
  </ParamField>

  **Response**

  <ResponseField name="total" type="decimal">
    Total payment amount
  </ResponseField>

  <ResponseField name="principal" type="decimal">
    Amount applied to principal
  </ResponseField>

  <ResponseField name="interest" type="decimal">
    Amount applied to interest
  </ResponseField>

  <ResponseField name="penalty" type="decimal">
    Amount applied to penalties
  </ResponseField>

  <ResponseField name="earlyRepaymentFee" type="decimal">
    Early repayment fee (if applicable)
  </ResponseField>

  <ResponseField name="timestamp" type="datetime">
    Payment timestamp
  </ResponseField>

  <ResponseField name="repaymentType" type="string">
    Type of repayment
  </ResponseField>

  <ResponseField name="paymentMethod" type="long">
    Payment method ID
  </ResponseField>

  <CodeGroup>
  ```bash cURL
  curl -X POST "https://api.opencbs.com/api/loans/12345/repayment/split" \
    -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "timestamp": "2024-03-15T10:00:00",
      "total": 1000.00,
      "repaymentType": "NORMAL_REPAYMENT",
      "paymentMethod": 1
    }'
  ```

  ```javascript JavaScript
  const response = await fetch('https://api.opencbs.com/api/loans/12345/repayment/split', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_ACCESS_TOKEN',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      timestamp: '2024-03-15T10:00:00',
      total: 1000.00,
      repaymentType: 'NORMAL_REPAYMENT',
      paymentMethod: 1
    })
  });
  const split = await response.json();
  console.log(`Principal: ${split.principal}, Interest: ${split.interest}`);
  ```

  ```python Python
  import requests

  response = requests.post(
    'https://api.opencbs.com/api/loans/12345/repayment/split',
    headers={'Authorization': 'Bearer YOUR_ACCESS_TOKEN'},
    json={
      'timestamp': '2024-03-15T10:00:00',
      'total': 1000.00,
      'repaymentType': 'NORMAL_REPAYMENT',
      'paymentMethod': 1
    }
  )
  split = response.json()
  print(f"Principal: {split['principal']}, Interest: {split['interest']}")
  ```
  </CodeGroup>
</Expandable>

## Preview Repayment Impact

<Expandable title="POST /api/loans/{loanId}/repayment/preview">
  Preview how a repayment will affect the loan schedule without actually processing the payment.

  <ParamField path="loanId" type="long" required>
    Loan identifier
  </ParamField>

  **Request Body**

  <ParamField body="timestamp" type="datetime" required>
    Payment date and time
  </ParamField>

  <ParamField body="total" type="decimal">
    Total payment amount (optional if providing component amounts)
  </ParamField>

  <ParamField body="principal" type="decimal">
    Principal amount (if specifying component amounts)
  </ParamField>

  <ParamField body="interest" type="decimal">
    Interest amount (if specifying component amounts)
  </ParamField>

  <ParamField body="penalty" type="decimal">
    Penalty amount (if specifying component amounts)

## Process Repayment

<Expandable title="POST /api/loans/{loanId}/repayment/repay">
  Submit a loan repayment for processing. This creates a maker-checker request that requires approval.

  <ParamField path="loanId" type="long" required>
    Loan identifier
  </ParamField>

  **Request Body**

  <ParamField body="timestamp" type="datetime" required>
    Effective date and time of the repayment
  </ParamField>

  <ParamField body="total" type="decimal" required>
    Total payment amount
  </ParamField>

  <ParamField body="principal" type="decimal">
    Principal amount (if specifying split manually)
  </ParamField>

  <ParamField body="interest" type="decimal">
    Interest amount (if specifying split manually)
  </ParamField>

  <ParamField body="penalty" type="decimal">
    Penalty amount (if specifying split manually)
  </ParamField>

  <ParamField body="earlyRepaymentFee" type="decimal">
    Early repayment fee (calculated automatically for early repayments)
  </ParamField>

  <ParamField body="repaymentType" type="string" required>
    Repayment type (NORMAL_REPAYMENT, EARLY_TOTAL_REPAYMENT, EARLY_PARTIAL_REPAYMENT)
  </ParamField>

  <ParamField body="paymentMethod" type="long" required>

  </ParamField>

## Repayment Types

<Expandable title="Understanding Repayment Types">
  The `repaymentType` parameter determines how the payment is processed and whether early repayment fees apply.

  ### NORMAL_REPAYMENT
  
  Regular scheduled repayment on or near the due date. The payment is applied to overdue amounts first, then to the current installment.

  **Use cases:**
  - Borrower paying monthly installment on time
  - Paying overdue installments
  - Regular payment schedules

  **Behavior:**
  - No early repayment fees
  - Follows standard payment allocation rules
  - Applied to oldest outstanding amounts first

  ### EARLY_TOTAL_REPAYMENT
  
  Complete payoff of the entire remaining loan balance before the maturity date.

  **Use cases:**
  - Borrower wants to close the loan completely
  - Refinancing to another institution
  - Paying off loan early with lump sum

  **Behavior:**
  - May incur early total repayment fee (based on product configuration)
  - Closes all remaining installments
  - Loan status changes to CLOSED
  - Calculates remaining principal + accrued interest + fees

  ### EARLY_PARTIAL_REPAYMENT
  
  Extra payment beyond the scheduled installment amount, reducing future installments or loan term.

  **Use cases:**
  - Borrower makes additional payment to reduce debt
  - Lump sum payment from bonus or windfall
  - Accelerating loan payoff

  **Behavior:**
  - May incur early partial repayment fee (based on product configuration)
  - Excess amount applied to future principal
  - Can reduce future installment amounts or shorten loan term (based on product settings)
  - Does not close the loan

  ### Example: Early Repayment Fees

  If a loan product has:
  - Early partial repayment fee: 2% of extra amount
  - Early total repayment fee: 5% of remaining principal

  **Scenario 1: Early Partial Repayment**
  ```json
  {
    "total": 2000.00,
    "repaymentType": "EARLY_PARTIAL_REPAYMENT"
  }
  ```
  If the scheduled payment is $955.50, the extra $1044.50 incurs a 2% fee ($20.89).

  **Scenario 2: Early Total Repayment**
  ```json
  {
    "total": 10500.00,
    "repaymentType": "EARLY_TOTAL_REPAYMENT"
  }
  ```
  If remaining principal is $10,000, a 5% fee ($500) is added to the payoff amount.

## Payment Methods

<Expandable title="Working with Payment Methods">
  The `paymentMethod` parameter identifies how the payment was received. Payment methods are configured in your OpenCBS instance.

  ### Common Payment Methods

  - **Cash**: Direct cash payment at branch
  - **Bank Transfer**: Electronic bank transfer
  - **Check**: Paper check
  - **Mobile Money**: Mobile wallet payment (M-Pesa, etc.)
  - **Card**: Credit/debit card payment
  - **Direct Debit**: Automatic bank withdrawal

  ### Getting Available Payment Methods

  To retrieve the list of available payment methods and their IDs:

  ```bash
  curl -X GET "https://api.opencbs.com/api/payment-methods" \
    -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
  ```

  Response:
  ```json
  [
    {"id": 1, "name": "Cash"},
    {"id": 2, "name": "Bank Transfer"},
    {"id": 3, "name": "Check"},
    {"id": 4, "name": "Mobile Money"}
  ]
  ```
</Expandable>

## Best Practices

<Expandable title="Repayment Processing Best Practices">
  ### 1. Always Use Preview First

  Before processing a repayment, use the preview endpoint to show the borrower exactly how their payment will be applied:

  ```javascript
  // Step 1: Preview
  const preview = await previewRepayment(loanId, amount);
  console.log(`Principal: ${preview.principal}, Interest: ${preview.interest}`);
  
  // Step 2: Confirm with borrower
  if (borrowerConfirms) {
    // Step 3: Process
    await processRepayment(loanId, amount);
  }
  ```

  ### 2. Calculate Split for Accurate Allocation

  Use the split endpoint to get the exact breakdown before submission:

  ```javascript
  const split = await calculateSplit(loanId, {
    total: 1000,
    repaymentType: 'NORMAL_REPAYMENT'
  });
  
  // Submit with calculated split
  await processRepayment(loanId, split);
  ```

  ### 3. Handle Maker-Checker Workflow

  Repayments require approval. Track the request status:

  ```javascript
  const { id: requestId } = await processRepayment(loanId, payment);
  
  // Later: Check request status
  const status = await checkRequestStatus(requestId);
  if (status === 'APPROVED') {
    console.log('Repayment processed successfully');
  }
  ```

  ### 4. Store Transaction References

  Always include reference information in the `extra` field:

  ```json
  {
    "timestamp": "2024-03-15T10:00:00",
    "total": 955.50,
    "repaymentType": "NORMAL_REPAYMENT",
    "paymentMethod": 3,
    "extra": "Check #12345 | Bank: ABC Bank | Date: 2024-03-15"
  }
  ```

  ### 5. Handle Partial Payments

  If borrower cannot pay full installment:

  ```javascript
  // Calculate what they can pay
  const split = await calculateSplit(loanId, {
    total: 500,  // Partial amount
    repaymentType: 'NORMAL_REPAYMENT'
  });
  
  // Show borrower the allocation
  console.log(`This pays ${split.interest} interest and ${split.principal} principal`);
  console.log(`Remaining due: ${installmentAmount - 500}`);
  ```

  ### 6. Actualize Before Processing

  Ensure the loan is actualized to the payment date:

  ```javascript
  // Actualize first
  await actualizeLoan(loanId, paymentDate);
  
  // Then process repayment
  await processRepayment(loanId, payment);
  ```
</Expandable>

## Error Handling

<Expandable title="Common Errors and Solutions">
  ### Loan Not Actualized

  **Error**: "Loan is not actualized to the payment date"

  **Solution**: Actualize the loan first:
  ```bash
  curl -X POST "https://api.opencbs.com/api/loans/actualize/12345?date=2024-03-15" \
    -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
  ```

  ### Invalid Payment Amount

  **Error**: "Payment amount exceeds total outstanding balance"

  **Solution**: For total payoff, use `EARLY_TOTAL_REPAYMENT` type and calculate exact amount:
  ```javascript
  const split = await calculateSplit(loanId, {
    total: 999999,  // Large number
    repaymentType: 'EARLY_TOTAL_REPAYMENT'
  });
  // Use split.total as exact payoff amount
  ```

  ### Invalid Repayment Date

  **Error**: "Repayment date is before disbursement date"

  **Solution**: Ensure timestamp is after loan disbursement and not in the future.

  ### Payment Method Not Found

  **Error**: "Payment method with id X not found"

  **Solution**: Retrieve valid payment method IDs:
  ```bash
  curl -X GET "https://api.opencbs.com/api/payment-methods" \
    -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
  ```
</Expandable>
