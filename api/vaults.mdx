## Overview

The Vaults API provides endpoints for managing vaults (secure cash storage facilities), including creation, retrieval, and updates of vault information.

## Get All Vaults

<CodeGroup>
```http GET /api/vaults
GET /api/vaults?page={page}&size={size}
```
</CodeGroup>

Retrieve all vaults with pagination.

### Query Parameters

<ParamField query="page" type="integer">
  Page number for pagination (0-based)
</ParamField>

<ParamField query="size" type="integer">
  Number of items per page
</ParamField>

### Response

<ResponseField name="content" type="array">
  Array of vault objects
  <ResponseField name="id" type="long">
    Vault ID
  </ResponseField>
  <ResponseField name="name" type="string">
    Vault name
  </ResponseField>
  <ResponseField name="branchId" type="long">
    Branch ID where the vault is located
  </ResponseField>
  <ResponseField name="accounts" type="array">
    Array of accounts associated with the vault
  </ResponseField>
</ResponseField>

## Create Vault

<CodeGroup>
```http POST /api/vaults
POST /api/vaults
Content-Type: application/json
```

```json Request Body
{
  "name": "Main Branch Vault",
  "branchId": 1,
  "currencyIds": [1, 2, 3]
}
```
</CodeGroup>

Create a new vault with accounts for specified currencies.

### Request Body

<ParamField body="name" type="string" required>
  Vault name
</ParamField>

<ParamField body="branchId" type="long" required>
  Branch ID where the vault will be located
</ParamField>

<ParamField body="currencyIds" type="array" required>
  Array of currency IDs for which accounts should be created
</ParamField>

### Response

Returns the created vault object with the same structure as Get Vault by ID.

### Example Response

## Vault Operations

Vaults interact with tills through transfer operations. See the [Tills API](/api/tills) for transfer endpoints:

- **Transfer to Vault**: `POST /api/tills/transfer/vault`
- **Transfer from Vault**: `POST /api/tills/transfer/till`

These operations allow moving funds between tills and vaults while maintaining proper accounting entries.

## Account Structure

Each vault automatically creates accounts for each specified currency. These accounts:

- Are linked to the branch's chart of accounts
- Track cash balances for each currency separately
- Follow standard double-entry accounting principles
- Maintain audit trails for all transactions
- Are sorted alphabetically by currency name in API responses

## Best Practices

### Vault Setup

1. Create vaults at the branch level
2. Configure all currencies that will be handled at that branch
3. Ensure proper permissions are assigned for vault operations

### Cash Management

1. Transfer excess till cash to vaults at end of day
2. Replenish tills from vaults at start of day
3. Regularly reconcile vault balances with physical cash counts
4. Maintain proper documentation for all vault transfers

### Security

1. Limit access to vault operations based on user roles
2. Require dual authorization for large transfers
3. Implement maker-checker workflows for vault creation/updates
4. Review vault operation logs regularly for audit purposes
