## Overview

The Borrowings API allows you to create and manage borrowing instruments (institutional borrowing/debt). All endpoints are located under `/api/borrowings`.

## Create Borrowing

<ParamField path="POST /api/borrowings" type="endpoint">
  Creates a new borrowing instrument.
</ParamField>

### Request Body

<ParamField body="profileId" type="long" required>
  The ID of the profile (lender) associated with this borrowing
</ParamField>

<ParamField body="productId" type="long" required>
  The ID of the borrowing product to use
</ParamField>

<ParamField body="amount" type="decimal" required>
  The principal amount to borrow
</ParamField>

<ParamField body="interestRate" type="decimal" required>
  The interest rate for the borrowing
</ParamField>

<ParamField body="maturityDate" type="date" required>
  The maturity date of the borrowing
</ParamField>

<ParamField body="scheduleType" type="string" required>
  The repayment schedule type (e.g., ANNUITY, EQUAL_INSTALLMENTS)
</ParamField>

### Response

<ResponseField name="id" type="long">
  The unique identifier of the created borrowing
</ResponseField>

<ResponseField name="status" type="string">
  Current status of the borrowing (e.g., PENDING, ACTIVE, CLOSED)
</ResponseField>

<ResponseField name="principal" type="decimal">
  The principal amount
</ResponseField>

<CodeGroup>
```bash cURL
curl -X POST https://api.opencbs.com/api/borrowings \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "profileId": 123,
    "productId": 456,
    "amount": 500000.00,
    "interestRate": 7.5,
    "maturityDate": "2031-03-14",
    "scheduleType": "ANNUITY"
  }'
```

```json Response
{
  "id": 789,
  "profileId": 123,
  "productId": 456,
  "status": "PENDING",
  "principal": 500000.00,
  "interestRate": 7.5,
  "maturityDate": "2031-03-14"
}
```
</CodeGroup>

## Get All Borrowings

  Retrieves all borrowings with optional search.
</ParamField>

</ParamField>

<ParamField query="page" type="integer">
  Page number for pagination (0-based)
</ParamField>

<ParamField query="size" type="integer">

## Borrowing Repayment

<ParamField path="POST /api/borrowings/{borrowingId}/repayment/repay" type="endpoint">
  Processes a repayment for the borrowing.
</ParamField>

### Path Parameters

<ParamField path="borrowingId" type="long" required>
  The ID of the borrowing
</ParamField>

### Request Body

<ParamField body="timestamp" type="datetime" required>
  The timestamp of the repayment
</ParamField>

<ParamField body="total" type="decimal" required>
  The total repayment amount
</ParamField>

<ParamField body="repaymentType" type="string" required>
  Type of repayment (e.g., NORMAL_REPAYMENT, EARLY_PARTIAL_REPAYMENT)
</ParamField>

<CodeGroup>
```bash cURL
curl -X POST https://api.opencbs.com/api/borrowings/789/repayment/repay \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "timestamp": "2026-06-14T10:00:00",
    "total": 15000.00,
    "repaymentType": "NORMAL_REPAYMENT"
  }'
```

```json Response
{
  "id": 789,
  "status": "ACTIVE",
  "paidPrincipal": 10000.00,
  "paidInterest": 5000.00,
  "olb": 490000.00
}
```
</CodeGroup>

## Roll Back Events

<ParamField path="POST /api/borrowings/{borrowingId}/roll-back" type="endpoint">
  Rolls back the most recent event on the borrowing.
</ParamField>

### Path Parameters

<ParamField path="borrowingId" type="long" required>
  The ID of the borrowing
</ParamField>

### Request Body

<ParamField body="comment" type="string" required>
  Comment explaining the reason for rollback
</ParamField>

<CodeGroup>
```bash cURL
curl -X POST https://api.opencbs.com/api/borrowings/789/roll-back \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "comment": "Incorrect payment amount entered"
  }'
```

```json Response
{
  "id": 789,
  "status": "ACTIVE",
  "lastEventRolledBack": true
}
```
</CodeGroup>

## Actualize Borrowing

<ParamField path="POST /api/borrowings/actualize/{borrowingId}" type="endpoint">
  Actualizes the borrowing to a specific date (processes accruals, late fees).
</ParamField>

### Path Parameters

<ParamField path="borrowingId" type="long" required>
  The ID of the borrowing to actualize
</ParamField>

### Query Parameters

<ParamField query="date" type="date" required>
  The date to actualize to (ISO date format)
</ParamField>

<CodeGroup>
```bash cURL
curl -X POST "https://api.opencbs.com/api/borrowings/actualize/789?date=2026-04-14" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```json Response
"Actualize borrowing started"
```
</CodeGroup>
