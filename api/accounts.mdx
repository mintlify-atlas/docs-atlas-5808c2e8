## Overview

The Accounts API provides endpoints for managing the chart of accounts, including account lookup, retrieval, creation, and balance operations.

## Get Account Lookup

<CodeGroup>
```http GET /api/accounting/lookup
GET /api/accounting/lookup?search={search}&page={page}&size={size}
```
</CodeGroup>

Search and retrieve accounts based on various criteria.

### Query Parameters

<ParamField query="search" type="string">
  Search term to filter accounts
</ParamField>

<ParamField query="page" type="integer">
  Page number for pagination (0-based)
</ParamField>

<ParamField query="size" type="integer">
  Number of items per page
</ParamField>

### Response

<ResponseField name="content" type="array">
  Array of account objects
  <ResponseField name="id" type="long">
    Account ID
  </ResponseField>
  <ResponseField name="number" type="string">
    Account number
  </ResponseField>
  <ResponseField name="name" type="string">
    Account name
  </ResponseField>
  <ResponseField name="balance" type="decimal">
    Current account balance
  </ResponseField>
</ResponseField>

## Create Account

<CodeGroup>
```http POST /api/accounting/chart-of-accounts
POST /api/accounting/chart-of-accounts
Content-Type: application/json
```

```json Request Body
{
  "name": "Cash Account",
  "number": "1000",
  "parentId": 1,
  "typeId": 1,
  "branchId": 1,
  "currencyId": 1,
  "isDebit": true
}
```
</CodeGroup>

Create a new account in the chart of accounts. This operation requires maker-checker approval.

### Request Body

<ParamField body="name" type="string" required>
  Account name
</ParamField>

<ParamField body="number" type="string" required>
  Account number
</ParamField>

<ParamField body="parentId" type="long">
  Parent account ID (for sub-accounts)
</ParamField>

<ParamField body="typeId" type="long" required>
  Account type ID
</ParamField>

<ParamField body="branchId" type="long" required>
  Branch ID
</ParamField>

<ParamField body="currencyId" type="long" required>
  Currency ID
</ParamField>

<ParamField body="isDebit" type="boolean" required>
  Whether the account is a debit account
</ParamField>

### Response

<ResponseField name="id" type="long">
  Request ID for maker-checker approval
</ResponseField>

### Permissions

Requires `MAKER_FOR_ACCOUNT` permission in the `MAKER_CHECKER` module.

### Response

### Permissions

Requires `MAKER_FOR_ACCOUNT` permission in the `MAKER_CHECKER` module.
