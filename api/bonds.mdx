## Overview

The Bonds API allows you to create, manage, and trade bond instruments. All endpoints are located under `/api/bonds`.

## Create Bond

<ParamField path="POST /api/bonds" type="endpoint">
  Creates a new bond instrument.
</ParamField>

### Request Body

<ParamField body="profileId" type="long" required>
  The ID of the profile (issuer) associated with this bond
</ParamField>

<ParamField body="productId" type="long" required>
  The ID of the bond product to use
</ParamField>

<ParamField body="faceValue" type="decimal" required>
  The face value of the bond
</ParamField>

<ParamField body="couponRate" type="decimal" required>
  The coupon rate (interest rate) of the bond
</ParamField>

<ParamField body="maturityDate" type="date" required>
  The maturity date of the bond
</ParamField>

<ParamField body="issueDate" type="date" required>
  The issue date of the bond
</ParamField>

### Response

<ResponseField name="id" type="long">
  The unique identifier of the created bond
</ResponseField>

<ResponseField name="status" type="string">
  Current status of the bond (e.g., IN_PROGRESS, ACTIVE, MATURED)
</ResponseField>

<ResponseField name="faceValue" type="decimal">
  The face value of the bond
</ResponseField>

<CodeGroup>
```bash cURL
curl -X POST https://api.opencbs.com/api/bonds \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "profileId": 123,
    "productId": 456,
    "faceValue": 100000.00,
    "couponRate": 6.5,
    "maturityDate": "2030-03-14",
    "issueDate": "2026-03-14"
  }'
```

```json Response
{
  "id": 789,
  "profileId": 123,
  "productId": 456,
  "status": "IN_PROGRESS",
  "faceValue": 100000.00,
  "couponRate": 6.5,
  "maturityDate": "2030-03-14",
  "issueDate": "2026-03-14"
}
```
</CodeGroup>

## Bond Repayment

<ParamField path="POST /api/bonds/{bondId}/repayment/repay" type="endpoint">
  Processes a repayment for the bond.
</ParamField>

### Path Parameters

<ParamField path="bondId" type="long" required>
  The ID of the bond
</ParamField>

### Request Body

<ParamField body="timestamp" type="datetime" required>
  The timestamp of the repayment
</ParamField>

<ParamField body="total" type="decimal" required>
  The total repayment amount
</ParamField>

<ParamField body="repaymentType" type="string" required>
  Type of repayment (e.g., NORMAL_REPAYMENT, EARLY_TOTAL_REPAYMENT)
</ParamField>

<CodeGroup>
```bash cURL
curl -X POST https://api.opencbs.com/api/bonds/789/repayment/repay \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "timestamp": "2026-06-14T10:00:00",
    "total": 3250.00,
    "repaymentType": "NORMAL_REPAYMENT"
  }'
```

```json Response
{
  "id": 789,
  "status": "ACTIVE",
  "paidPrincipal": 0.00,
  "paidInterest": 3250.00
}
```
</CodeGroup>
