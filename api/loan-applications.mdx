---
title: "Loan Applications API"
description: "Manage loan application workflow from creation to disbursement"
---

The Loan Applications API manages the complete loan origination workflow, from initial application creation through approval and disbursement. Applications go through various statuses: IN_PROGRESS → PENDING → APPROVED → DISBURSED.

## Create Loan Application

<Expandable title="POST /api/loan-applications">
  Create a new loan application.

  **Request Body**

  <ParamField body="profileId" type="long" required>
    Borrower profile identifier
  </ParamField>

  <ParamField body="loanProductId" type="long" required>
    Loan product identifier
  </ParamField>

  <ParamField body="amounts" type="array" required>
    Loan amounts (for group loans, specify per member)
    
    <Expandable title="Amount Object">
      <ParamField body="amount" type="decimal" required>
        Loan amount
      </ParamField>

      <ParamField body="memberId" type="long">
        Group member ID (for group loans only)
      </ParamField>
    </Expandable>
  </ParamField>

  <ParamField body="disbursementDate" type="date" required>
    Planned disbursement date (YYYY-MM-DD)
  </ParamField>

  <ParamField body="preferredRepaymentDate" type="date">
    Preferred first repayment date
  </ParamField>

  <ParamField body="maturity" type="integer" required>
    Loan term (number of installments or days)
  </ParamField>

  <ParamField body="gracePeriod" type="integer">
    Grace period (default: 0)
  </ParamField>

  <ParamField body="interestRate" type="decimal" required>
    Annual interest rate
  </ParamField>

  <ParamField body="scheduleType" type="string" required>
    Schedule generation type (ANNUITY, FLAT, DECLINING_BALANCE, etc.)
  </ParamField>

  <ParamField body="scheduleBasedType" type="string">
    DAILY_INSTALLMENT or MONTHLY_INSTALLMENT
  </ParamField>

  <ParamField body="currencyId" type="long" required>
    Currency identifier
  </ParamField>

  <ParamField body="userId" type="long" required>
    Loan officer user ID
  </ParamField>

  <ParamField body="payees" type="array">
    Disbursement payees (if product supports multiple payees)
    
    <Expandable title="Payee Object">
      <ParamField body="name" type="string" required>
        Payee name
      </ParamField>

      <ParamField body="amount" type="decimal" required>
        Amount to disburse to this payee
      </ParamField>

      <ParamField body="description" type="string">
        Purpose description
      </ParamField>
    </Expandable>
  </ParamField>

  <ParamField body="entryFees" type="array">
    Entry fees to apply
    
    <Expandable title="Entry Fee Object">
      <ParamField body="feeId" type="long" required>
        Fee identifier
      </ParamField>

      <ParamField body="amount" type="decimal">
        Fee amount (if not using percentage)
      </ParamField>

      <ParamField body="percentage" type="decimal">
        Fee percentage (if not using fixed amount)
      </ParamField>
    </Expandable>
  </ParamField>

  <ParamField body="penaltyIds" type="array">
    Array of penalty IDs to apply
  </ParamField>

  <ParamField body="fieldValues" type="array">
    Custom field values
  </ParamField>

  <ParamField body="creditLineId" type="long">
    Credit line to use (if applicable)
  </ParamField>

  **Response**: Complete loan application object with generated code, schedule, and status.

  <CodeGroup>
  ```bash cURL
  curl -X POST "https://api.opencbs.com/api/loan-applications" \
    -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "profileId": 123,
      "loanProductId": 1,
      "amounts": [{"amount": 10000}],
      "disbursementDate": "2024-04-01",
      "maturity": 12,
      "gracePeriod": 0,
      "interestRate": 12.5,
      "scheduleType": "ANNUITY",
      "currencyId": 1,
      "userId": 5
    }'
  ```

  ```javascript JavaScript
  const response = await fetch('https://api.opencbs.com/api/loan-applications', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_ACCESS_TOKEN',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      profileId: 123,
      loanProductId: 1,
      amounts: [{amount: 10000}],
      disbursementDate: '2024-04-01',
      maturity: 12,
      gracePeriod: 0,
      interestRate: 12.5,
      scheduleType: 'ANNUITY',
      currencyId: 1,
      userId: 5
    })
  });
  const application = await response.json();
  ```

  ```python Python
  import requests

  response = requests.post(
    'https://api.opencbs.com/api/loan-applications',
    headers={'Authorization': 'Bearer YOUR_ACCESS_TOKEN'},
    json={
      'profileId': 123,
      'loanProductId': 1,
      'amounts': [{'amount': 10000}],
      'disbursementDate': '2024-04-01',
      'maturity': 12,
      'gracePeriod': 0,
      'interestRate': 12.5,
      'scheduleType': 'ANNUITY',
      'currencyId': 1,
      'userId': 5
    }
  )
  application = response.json()
  ```
  </CodeGroup>
</Expandable>

  ```javascript JavaScript
  });
  ```

