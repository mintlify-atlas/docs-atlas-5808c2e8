## Core Domain Entities

The core module defines fundamental domain entities that represent the basic building blocks of the system.

### Profile

The `Profile` entity is the base class for all customer types (persons, companies, groups). It uses single-table inheritance to support multiple profile types.

**Location:** `server/opencbs-core/src/main/java/com/opencbs/core/domain/profiles/Profile.java`

```java
@Entity
@Table(name = "profiles")
@Inheritance(strategy = InheritanceType.SINGLE_TABLE)
@DiscriminatorColumn(name = "[type]", discriminatorType = DiscriminatorType.STRING)
public class Profile extends CreationInfoEntity implements NamedEntity {
    private String type;
    private String name;
    private EntityStatus status;
    private Branch branch;
    private Set<Account> currentAccounts;
}
```

<Accordion title="Profile Hierarchy">
  - **Profile** (base class)
    - **Person** - Individual customers
    - **Company** - Corporate customers
    - **Group** - Group lending customers
</Accordion>

## Schedule Generation

The core module provides a flexible schedule generation system supporting multiple algorithms and frequencies.

### Schedule Generator Interface

**Location:** `server/opencbs-core/src/main/java/com/opencbs/core/services/schedulegenerators/ScheduleGenerator.java:9`

```java
public interface ScheduleGenerator {
    RoundingMode ROUNDING_MODE = RoundingMode.HALF_EVEN;
    int DECIMAL_PLACE = 2;
    
    List<Installment> getSchedule(ScheduleParams params);
    int getDaysInPeriod();
    ScheduleGeneratorTypes getType();
}
```

### Supported Generator Types

<Tabs>
  <Tab title="Annuity">
    Equal installments with decreasing interest and increasing principal.
    
    **Implementations:**
    - Monthly (`AnnuityMonthlyGenerator`)
    - Quarterly (`AnnuityQuarterlyGenerator`)
    - Semi-annually (`AnnuitySemiannuallyGenerator`)
    - Annually (`AnnuityAnnuallyGenerator`)
    - Bi-weekly (`AnnuityBiweeklyGenerator`)
  </Tab>
  <Tab title="Fixed Principal">
    Fixed principal amount with decreasing interest.
    
    **Implementations:**
    - Monthly (`FixedPrincipalMonthlyGenerator`)
    - Quarterly (`FixedPrincipalQuarterlyGenerator`)
    - Annually (`FixedPrincipalAnnuallyGenerator`)
    - Bi-weekly (`FixedPrincipalBiweeklyGenerator`)
  </Tab>
  <Tab title="Flat">
    Equal principal and interest throughout the term.
    
    **Implementations:**
    - Monthly (`FlatMonthlyGenerator`)
    - Quarterly (`FlatQuarterlyGenerator`)
    - Annually (`FlatAnnuallyGenerator`)
    - Bi-annually (`FlatBiAnnuallyGenerator`)
  </Tab>
  <Tab title="Maturity">
    Principal and interest paid at maturity.
    
    **Implementations:**
    - Quarterly Actual/360 (`MaturityQuarterlyActual360Generator`)
  </Tab>
</Tabs>

<Accordion title="Day Closure Process">
  1. **Pre-closure Validation** - Ensure all transactions are complete
  2. **Contract Processing** - Process accruals, provisions, penalties
  3. **Accounting Entries** - Generate day-end accounting entries
  4. **Post-closure Tasks** - Update balances and generate reports
</Accordion>
