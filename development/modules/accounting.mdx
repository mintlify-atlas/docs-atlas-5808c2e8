The accounting subsystem within the `opencbs-core` module provides a complete double-entry accounting engine supporting multi-currency operations, hierarchical account structures, and automated accounting entry generation.

## Overview

The accounting engine is a critical component that ensures financial integrity across all OpenCBS operations.

## Accounting Domain Model

The accounting domain model consists of accounts and entries.

### Account Entity

**Location:** `server/opencbs-core/src/main/java/com/opencbs/core/accounting/domain/Account.java`

Accounts represent GL (General Ledger) accounts in the chart of accounts.

```java
@Entity
@Table(name = "accounts")
public class Account extends BaseEntity {
    private String number;
    private String name;
    private AccountType type;
    private Account parent;
    private Currency currency;
    private Boolean isDebit;
    private Boolean locked;
    private Boolean validateOff;
    private Branch branch;
}
```

### Account Hierarchy

The chart of accounts uses a hierarchical structure:

<Accordion title="Account Type Hierarchy">
  **BALANCE (Root Level)**
  - Assets
  - Liabilities
  - Equity
  
  **GROUP (Category Level)**
  - Current Assets
  - Fixed Assets
  - Current Liabilities
  - Long-term Liabilities
  - Retained Earnings
  
  **SUBGROUP (Subcategory Level)**
  - Cash and Cash Equivalents
  - Accounts Receivable
  - Loan Portfolio
  - Savings Accounts
  - Interest Payable
  
  **ACCOUNT (Detail Level)**
  - Specific GL accounts for transactions
  - Example: "1010 - Cash on Hand"
  - Example: "1400 - Loan Portfolio - Consumer Loans"
</Accordion>

### Account Properties

<Tabs>
  <Tab title="Core Properties">
    **Number** - Unique account number
    
    **Name** - Account description
    
    **Type** - Account type in hierarchy
    ```
    BALANCE, GROUP, SUBGROUP, ACCOUNT
    ```
    
    **Parent** - Parent account in hierarchy
    
    **Currency** - Account currency
  </Tab>
  <Tab title="Behavior Flags">
    **isDebit** - Normal balance side
    - `true` = Debit balance (Assets, Expenses)
    - `false` = Credit balance (Liabilities, Equity, Income)
    
    **locked** - Account lock status
    - Locked accounts cannot have transactions
    
    **validateOff** - Skip validation
    - Allows negative balances when disabled
  </Tab>
  <Tab title="Additional Info">
    **Branch** - Branch assignment
    
    **Tags** - Flexible tagging system
    - System tags for special accounts
    - User-defined tags for reporting
    
    **Extended Tags** - Additional metadata
  </Tab>
</Tabs>

## AccountingEntry Entity

**Location:** `server/opencbs-core/src/main/java/com/opencbs/core/accounting/domain/AccountingEntry.java:40`

Represents a single accounting entry (journal entry) in the system.

```java
@Entity
@Table(name = "accounting_entries")
public class AccountingEntry extends BaseEntity {
    private Account debitAccount;
    private Account creditAccount;
    private BigDecimal amount;
    private LocalDateTime createdAt;
    private LocalDateTime effectiveAt;
    private User createdBy;
    private Branch branch;
    private String description;
    private ExtraJson extra;
    private Boolean deleted;
}
```

### Entry Properties

<CardGroup cols={2}>
  <Card title="Accounts">
    **debitAccount** - Account to debit
    
    **creditAccount** - Account to credit
    
    Ensures double-entry: every debit has an equal credit
  </Card>
  <Card title="Amounts">
    **amount** - Transaction amount
    
    Must be positive (non-zero)
    
    Precision: 14 digits, 2 decimal places
  </Card>
  <Card title="Timestamps">
    **createdAt** - When entry was created
    
    **effectiveAt** - When entry takes effect
    
    Allows backdating for corrections
  </Card>
  <Card title="Metadata">
    **description** - Entry description
    
    **extra** - Additional JSON data
    
    **createdBy** - User who created entry
  </Card>
</CardGroup>

## Accounting Entry Service

The AccountingEntryService manages the creation and validation of accounting entries.

**Location:** `server/opencbs-core/src/main/java/com/opencbs/core/accounting/services/AccountingEntryService.java:38`

### Core Methods

<Tabs>
  <Tab title="Entry Creation">
    **create(AccountingEntry)** - Create single entry
    
    **create(List&lt;AccountingEntry&gt;)** - Create multiple entries
    
    Both methods validate entries before saving.
  </Tab>
  <Tab title="Entry Validation">
    **validateAccountingEntry(AccountingEntry)**
    
    Location: AccountingEntryService.java:50
    
    Validation checks:
    1. Currency match between debit and credit accounts
    2. Sufficient funds on credit accounts (for credit balance)
    3. Sufficient funds on debit accounts (for debit balance)
    4. Account not locked
    5. Amount is positive
  </Tab>
  <Tab title="Entry Queries">
    **findById(Long)** - Get entry by ID
    
    **findAll(Pageable)** - List all entries
    
    **getAll(SortedAccountingEntryDto, Pageable)** - Filtered query
    
    **getAccountingEntriesByAccount(Account, from, to)** - Account history
  </Tab>
  <Tab title="Account Operations">
    **findAccountOperations(Account, Pageable, from, to)**
    
    Location: AccountingEntryService.java:99
    
    Returns operations view with:
    - Running balance
    - Debit/credit amounts
    - Source account
    - Document reference
  </Tab>
</Tabs>

### Entry Validation Logic

The validation process ensures accounting integrity:

<Accordion title="Validation Rules">
  **Currency Match** (Line 56-57)
  ```java
  if (!debit.getCurrency().getId().equals(credit.getCurrency().getId()))
      throw new RuntimeException("Accounts have different currencies...");
  ```
  
  **Sufficient Funds - Credit Balance Account** (Line 58-59)
  ```java
  if (!debit.getIsDebit() && !debit.getValidateOff() && 
      accountService.getAccountBalance(...).compareTo(amount) < 0)
      throw new RuntimeException("Insufficient funds...");
  ```
  
  **Sufficient Funds - Debit Balance Account** (Line 60-61)
  ```java
  if (credit.getIsDebit() && !credit.getValidateOff() && 
      accountService.getAccountBalance(...).compareTo(amount) < 0)
      throw new RuntimeException("Insufficient funds...");
  ```
  
  **Account Locked Check** (Line 62-65)
  ```java
  if (debit.getLocked())
      throw new RuntimeException("Account is locked...");
  if (credit.getLocked())
      throw new RuntimeException("Account is locked...");
  ```
</Accordion>
