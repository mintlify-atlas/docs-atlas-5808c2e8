## Interest Calculation

The savings module implements sophisticated interest calculation with daily accrual and periodic posting.

### Interest Accrual Process

**Location:** `server/opencbs-savings/src/main/java/com/opencbs/savings/services/impl/SavingInterestAccrualDayClosureProcessor.java:33`

The interest accrual processor runs during day closure to calculate daily interest.

```java
@Service
public class SavingInterestAccrualDayClosureProcessor 
    implements SavingDayClosureProcessor {
    
    @Override
    public void processContract(Long savingId, 
                               LocalDate closureDate, 
                               User user) {
        SavingInterestAccrual saving = savingRepository.findOne(savingId);
        if (saving.getInterestRate().equals(BigDecimal.ZERO)) {
            return;
        }
        
        AccountingEntry entry = 
            createDailyAccrualEntry(saving, closureDate, user);
        if (entry.getAmount().compareTo(BigDecimal.ZERO) > 0) {
            accountingEntryService.save(entry);
        }
    }
}
```

### Interest Calculation Formula

**Location:** SavingInterestAccrualDayClosureProcessor.java:101

<Accordion title="Daily Interest Calculation">
  The daily interest is calculated as:
  
  ```
  Daily Interest = (Balance × Annual Rate) / Days in Year
  ```
  
  **Formula Details:**
  - Balance: End-of-day balance
  - Annual Rate: Interest rate percentage / 100
  - Days in Year: Actual days in the year (365 or 366)
  - Rounding: HALF_EVEN to 2 decimal places
  
  **Minimum Balance Check:**
  Interest is only calculated if the balance meets or exceeds the product's minimum balance requirement.
  
  **Accounting Entry:**
  - Debit: Interest Expense account
  - Credit: Interest Payable account
</Accordion>

## Fee Management

Savings accounts support multiple fee types applied at different lifecycle points.

### Fee Types and Application

<Accordion title="Fee Structure">
  **Entry Fee** - Applied when opening account
  - Rate-based (% of initial deposit)
  - Flat amount
  - Debited from first deposit
  
  **Deposit Fee** - Applied on each deposit
  - Rate-based (% of deposit amount)
  - Flat amount per transaction
  
  **Withdrawal Fee** - Applied on each withdrawal
  - Rate-based (% of withdrawal amount)
  - Flat amount per transaction
  
  **Management Fee** - Periodic fee for account maintenance
  - Rate-based (% of average balance)
  - Flat monthly/quarterly/annual amount
  - Applied during day closure
  
  **Close Fee** - Applied when closing account
  - Rate-based (% of closing balance)
  - Flat amount
</Accordion>

### Fee Calculation

Fees are calculated as:
```
Total Fee = (Amount × FeeRate / 100) + FeeFlat
```
