OpenCBS Cloud provides a powerful reporting system to help you analyze your institution's performance, monitor portfolio quality, and generate regulatory reports.

## Accessing Reports

Navigate to reports:

1. Click **Reports** in the main navigation menu
2. Browse available reports by category
3. Select the report you want to run

## Running a Report

<Steps>
  <Step title="Select Report">
    From the report list, click on the report you want to run:
    - View report description
    - Check required parameters
    - Review available output formats
  </Step>

  <Step title="Set Report Parameters">
    Configure the report parameters:

    ### Common Parameters

    **Date Range**
    - From date
    - To date
    - As of date (for point-in-time reports)

    **Filters**
    - Branch/office
    - Loan officer
    - Product type
    - Client type
    - Status

    **Grouping**
    - Group by branch
    - Group by product
    - Group by officer

    <Tip>
      Required parameters are marked with an asterisk (*). The report cannot run until all required parameters are provided.
    </Tip>
  </Step>

  <Step title="Preview Report">
    Click **Generate** or **Preview**:
    - Report renders in HTML format
    - Review data for accuracy
    - Verify date ranges and filters
    - Check calculations and totals
  </Step>

  <Step title="Export Report (Optional)">
    Export the report in your desired format:
    - **PDF** - For printing and archiving
    - **Excel (XLSX)** - For further analysis
    - **CSV** - For data import/integration

    Click the format button to download the file.
  </Step>
</Steps>

## Report Generation API

### Get Report HTML

Generate report preview:
```
POST /reports/html
```

Request body:
```json
{
  "reportName": "portfolio_outstanding",
  "reportLabel": "Outstanding Portfolio Report",
  "fieldsValues": {
    "fromDate": "2024-01-01",
    "toDate": "2024-12-31",
    "branch": "1",
    "format": "HTML"
  }
}
```

### Export Report File

Generate downloadable report:
```
POST /reports/file
```

Request body:
```json
{
  "reportName": "portfolio_outstanding",
  "reportLabel": "Outstanding Portfolio Report",
  "fieldsValues": {
    "fromDate": "2024-01-01",
    "toDate": "2024-12-31",
    "branch": "1",
    "format": "PDF"  // or "EXCEL" or "CSV"
  }
}
```

Response: Binary file download

## Key Portfolio Reports

### Portfolio at Risk (PAR)

Measures loan portfolio quality:

- **PAR > 0 days** - Any late payment
- **PAR > 30 days** - Payment over 30 days late
- **PAR > 60 days** - Payment over 60 days late
- **PAR > 90 days** - Payment over 90 days late

Calculation:
```
PAR = (Outstanding balance of loans with overdue payments) / (Total outstanding portfolio)
```

### Outstanding Loan Portfolio

Shows current portfolio composition:
- Total outstanding principal
- Number of active loans
- Average loan size
- Breakdown by product/branch/officer

### Disbursement Report

Tracks loan disbursements:
- Loans disbursed in period
- Total disbursement amount
- By product, branch, officer
- Disbursement trends

### Collection Report

Monitors repayment performance:
- Expected collections
- Actual collections
- Collection rate/efficiency
- Outstanding arrears

Access to reports is controlled by permissions:

- VIEW_REPORTS - View and run reports
- EXPORT_REPORTS - Export to PDF/Excel/CSV

## Performance Considerations

<Tip>
  **For Large Reports:**
  - Use specific date ranges rather than "all dates"
  - Apply filters to limit data volume
  - Export to Excel/CSV for very large datasets
  - Run resource-intensive reports during off-peak hours
  - Consider using summary reports instead of detailed reports
</Tip>

## Common Report Issues

| Issue | Solution |
|-------|----------|
| Report shows no data | Verify date range and filters |
| Numbers don't match expectations | Check as-of date and transaction timing |
| Report times out | Narrow date range or apply more filters |
| Export fails | Try smaller date range or CSV format |
| Missing transactions | Verify transaction status and dates |
| Permission denied | Contact administrator for report access |
